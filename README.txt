# Miley — Our Moonlit Princess

A standalone, mobile-friendly Princess Day website for Miley.

## Preview locally
Open `index.html` in a browser. Keep the `photos` folder beside it.

## Publish with GitHub Pages
1. Create a GitHub repository named `miley-princess-day`.
2. Extract this ZIP and upload **the contents** of the extracted folder to the repository root.
   - `index.html` must be directly in the root.
   - Keep the `photos` folder and all seven images intact.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. After GitHub Pages finishes deploying, the site should be available at:
   `https://shubhang7100.github.io/miley-princess-day/`

## Included
- `index.html` — complete website (HTML, CSS, JavaScript)
- `photos/` — all 7 uploaded photos

The gallery supports tap-to-expand photos, the letter is personalised for Miley, and the surprise button reveals a hidden message.
